Disini aku buat slicing web portofolio, nah fiturnya meliputi:

-Responsif Multi-Device:
Tata letak otomatis menyesuaikan ukuran layar (Desktop, Tablet, dan Mobile) menggunakan CSS Flexbox, Grid, dan Media Query.

-Filter Proyek Interaktif (JavaScript DOM):
Pengunjung dapat menyaring daftar pengalaman/proyek berdasarkan kategori (Semua, Ekstrakulikuler, Organisasi Mahasiswa) secara instan tanpa reload halaman.

-Showcase Profil & Riwayat Pendidikan:
Foto profil bulat dengan efek glow merah serta daftar riwayat pendidikan yang tersusun rapi dalam format dua kolom.

-Tautan Sosial Media & Kontak Cepat:
Tombol langsung menuju chat WhatsApp serta deretan tombol logo media sosial (Instagram, GitHub, LinkedIn, Facebook) berbentuk lingkaran dengan animasi glow/hover.
